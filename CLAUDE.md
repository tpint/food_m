# CLAUDE.md

## Workflow

- For every change: commit it, push the branch, open a pull request against `main`, and merge it automatically once CI passes. Fix any CI failure or merge conflict before merging; do not wait for confirmation.
- Work comes from the Trello board "food_m" (https://trello.com/b/RHJQ432b/foodm): cards in the To-Do list. Once a card's PR is merged, move the card to the Done list (top) without asking.
